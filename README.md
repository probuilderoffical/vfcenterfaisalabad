# VF Center Faisalabad

Official presentation and leasing website for VF Center Faisalabad, Main Jail Road, Faisalabad.

## Local preview

```bash
python3 -m http.server 4173 -d dist
```

The source is a lightweight static site in `dist/`, organized into conversion-friendly sections and reusable shared assets. Forms intentionally hand off to WhatsApp rather than simulating a backend submission.

## Content policy

Only details corroborated by VF Center's public pages, current official leasing artwork, Google Maps, or verified tenant sources are published. Availability and terms remain subject to management confirmation.
